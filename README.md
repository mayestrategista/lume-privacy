# Política de Privacidade — LUMÊ

**Última atualização:** maio de 2026

## 1. Sobre o aplicativo
O LUMÊ é um aplicativo de manifestação e bem-estar espiritual. Esta política descreve como tratamos seus dados ao usar o app.

## 2. Dados que coletamos
O LUMÊ **não coleta nem transmite dados pessoais para servidores externos**.

Todos os dados que você insere no app (nome, pedidos ao universo, gratidões, diário de sonhos, metas e frequências medidas) são armazenados **exclusivamente no seu dispositivo**, usando o armazenamento local do próprio celular. Esses dados nunca saem do seu aparelho.

## 3. Pagamentos e assinaturas
As assinaturas do LUMÊ Pro são processadas pelo **Google Play Billing**. O LUMÊ não tem acesso aos seus dados de pagamento (cartão de crédito, dados bancários, etc.). Todas as transações são gerenciadas diretamente pelo Google. Consulte a [Política de Privacidade do Google](https://policies.google.com/privacy) para mais detalhes.

## 4. Permissões do dispositivo
O app pode solicitar permissão para enviar **notificações**. Essa permissão é usada apenas para lembretes de uso do app (gratidão diária, medição de frequência, fases lunares). Nenhuma notificação coleta ou transmite dados pessoais.

## 5. Compartilhamento de dados
O LUMÊ não compartilha, vende nem transfere seus dados a terceiros.

## 6. Crianças
O LUMÊ não é direcionado a menores de 13 anos e não coleta intencionalmente dados de crianças.

## 7. Alterações nesta política
Podemos atualizar esta política eventualmente. A data de "última atualização" no topo sempre indicará a versão mais recente.
